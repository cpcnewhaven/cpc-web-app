# CPC New Haven Admin User Guide

This guide is for church staff, volunteers, and helpers who want to update the website without having to think about the technical side of the app.

## What the admin area is for

Use the admin area to manage the content that appears on the website:

- Announcements
- Events
- Sermons
- Podcasts
- Gallery images
- Teaching series
- Page content like About and Community
- User accounts for people who help with the site

## How to get in

1. Go to the site and open `/admin`
2. Log in with your admin username and password
3. You will land on the admin dashboard

If you are not able to log in, ask Chris or whoever manages admin accounts.

## The main idea

The admin works like a simple content editor:

- `Create` adds a new item
- `Edit` changes an existing item
- `Delete` removes an item
- `Active` usually means the item is visible on the site
- `Archive` means it is no longer current, but we keep it for reference

When in doubt, it is usually safer to archive something instead of deleting it.

## What to edit where

### Announcements

Use announcements for:

- Church notices
- Sunday reminders
- Weather or parking alerts
- Upcoming events that should appear on the homepage

Tips:

- Keep the title short and clear
- Put the important details in the description
- Use the image field if you want a banner or card to show a picture
- Check `Show in top bar` only for short alerts that should appear at the top of the site

### Events

Use events for:

- Ongoing church activities
- Repeating ministries
- Event listings that should appear on the Sundays or events pages

Tips:

- Use a clear title
- Add the date or timing in the description if needed
- Turn `Active` off when the event is no longer current

### Sermons

Use sermons for:

- Sunday preaching
- Sermon series organization
- Links to Spotify, YouTube, or podcast pages

Tips:

- Enter the sermon title
- Add the speaker name
- Add the scripture reference if you have it
- Add media links if they are available

### Podcasts

Use podcasts for:

- Podcast series names
- Individual podcast episodes
- Episode guests and links

Tips:

- Make sure the episode belongs to the right series
- Add a thumbnail image if one is available
- Keep episode titles consistent so the list is easy to scan

### Gallery

Use gallery for:

- Event photos
- Ministry photos
- Images that should appear in the media area of the site

Tips:

- Use clear names
- Add tags when helpful
- Only upload images you are comfortable showing publicly

### Teaching Series

Use teaching series for:

- Longer-form teaching content
- Session-based studies
- PDF handouts or session notes

Tips:

- Create the series first
- Then add sessions underneath it
- If a session has a PDF, upload it and paste the link

### Page Editors

Use page editors for:

- About page content
- Community page content
- Other editable page sections

This area is best for updating text, stories, ministry blurbs, and similar content.

## A simple workflow

1. Decide what type of content you are changing
2. Open the matching section in admin
3. Click `Create` or `Edit`
4. Fill in the form
5. Save your changes
6. Check the public page to make sure it looks right

## Before you save

Ask yourself:

- Is the title clear?
- Is the content in the right place?
- Is the item marked active if people should see it?
- Are dates correct?
- Are links working?
- Is the image the right one?

## What changes go live

Most saved changes show up on the live site right away.

That means:

- Be careful with edits
- Avoid experimenting on live content
- If you are unsure, ask first

## Safer choices

- Use `Archive` instead of `Delete` when possible
- Use `Active` to hide something temporarily
- Keep a backup or screenshot if you are making a big change
- Check the public page after editing

## For Chris and other helpers

If you are one of the more technical helpers, the admin area also includes more advanced tools:

- Live content
- Activity history
- Exports
- Reordering tools
- Upload tools
- Backup tools
- User management

Those tools are useful when you are helping the church stay organized, but they are not required for basic content editing.

## If something looks wrong

1. Refresh the page
2. Check the public site
3. Open Activity History if you need to see what changed
4. Ask Chris if the change should be kept or rolled back

## Good habits

- Use short, plain language
- Keep titles consistent
- Add images only when they help
- Remove old content only when you are sure it is no longer needed
- Double-check dates before saving

## One-sentence summary

If you only remember one thing: choose the right content section, make the change, save it, and then verify the public page.
